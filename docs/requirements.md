# 요구사항 확정서 (Requirements Specification)

> 문서 버전: 0.1 (단계 1 산출물) 기준 문서: 「결정의 나침반(Compass)」 워터폴 설계 명세

## 1. 개요

「결정의 나침반」은 사용자가 지치거나 위축되거나 공황 상태이거나 결정을 못 할 때, 동서양 운세·심리·뇌과학·한의학적 근거를 거울 삼아 더 나은 한 걸음으로 이끄는 개인 의사결정 상담 앱이다.

## 5. 가정(Assumptions)

- 사용자는 1단계에서 본인 또는 소수 신뢰 사용자로 제한된다.
- 골든 케이스(1980-03-19 01:45 대구 남)의 만세력 결과는 사용자가 제공한 값을 정답으로 받는다.
- 한국 표준시(UTC+9)를 기준으로 하되, 출생지 경도에 따른 진태양시 보정은 선택적으로 적용한다.
- 서머타임은 1948\~1988 한국 사례를 예외 테이블로 처리하며, 골든 케이스(1980)는 비해당이다.
