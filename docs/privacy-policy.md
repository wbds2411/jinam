# 개인정보 처리방침

시행일: 2026-07-13 · 버전: 1.0

## 처리 정보와 목적

결정의 나침반은 별칭, 성별, 생년월일·시각·지역, 선택형 심리·건강 맥락, 체크인, 상담 기록을 자기이해와 상담 기능 제공에 사용합니다. 선택 입력은 입력하지 않아도 됩니다.

## 저장과 보호

- 기본 저장 위치는 사용자의 기기입니다.
- 프로필·상담·API 키는 PIN에서 파생한 키로 AES-GCM 암호화합니다.
- PIN 검증에는 랜덤 salt와 PBKDF2-SHA256을 사용합니다.
- PIN은 계정 인증이나 안전한 하드웨어 키 저장소와 같지 않습니다. 기기 자체가 탈취·감염되면 보호를 보장할 수 없습니다.
- PIN을 잊으면 데이터를 복구할 수 없습니다.

## 외부 전송

프라이버시 모드는 기본으로 켜져 있습니다. 클라우드 LLM은 사용자가 모드를 끄고 별도 전송 동의를 한 경우에만 후보가 됩니다. 생년월일, 연락처, 건강·상담·사주 문맥을 감지하면 로컬 또는 오프라인 응답으로 전환합니다. 탐지는 규칙 기반이므로 완전한 비식별화를 보장하지 않습니다. BYOK API 키를 사용할 때 공급자의 약관과 개인정보 정책이 추가 적용됩니다.

## 보유·내보내기·삭제

정보는 사용자가 삭제할 때까지 기기에 보관됩니다. 설정에서 API 키를 제외한 데이터를 JSON으로 내보내거나 전체 데이터를 삭제할 수 있습니다. 앱 삭제 전 필요한 자료는 먼저 내보내야 합니다.

## 위기 및 민감정보

위기 표현은 안전 안내를 위해 기기에서 우선 감지합니다. 앱은 응급 서비스나 의료기관이 아니며 자동 신고 기능을 제공하지 않습니다. 즉각적인 위험이 있으면 현지 응급 서비스에 연락해야 합니다.

## 아동·청소년

만 14세 미만 사용자는 보호자의 동의와 도움 없이 개인정보를 입력하면 안 됩니다. 지역 법률이 더 높은 연령 또는 추가 동의를 요구하면 해당 기준을 따라야 합니다.

## 권리와 문의

사용자는 언제든 입력을 중단하고 데이터를 내보내거나 삭제할 수 있습니다. 정식 배포 전 운영 주체, 개인정보 보호 책임자, 연락처와 관할 지역을 확정해 이 문서를 갱신해야 합니다.
