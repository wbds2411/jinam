# 도메인 근거 자료 레이어 (Domain Sources)

> 문서 버전: 0.2 목적: 각 도구가 무엇에 근거하는지, 신뢰도는 어느 정도인지, 실제 사용 가능한 라이브러리/데이터는 무엇인지 명시. 단계 2에서 전 세계적 도메인을 추가함.

## 1. 신뢰도 등급 정의

| 등급 | 의미 | UI 표현 |
| --- | --- | --- |
| `verified` | 공개 데이터·검증된 알고리즘·재현 가능한 계산 | "계산 기반" 배지, 단정형 표현 |
| `conventional` | 전통 상징 체계·통념·문화적 해석 프레임워크 | "전통/상징적 관점" 배지, 서술형 표현 |
| `caution` | 과학적 근거 약함·개인차 큼·자기투사/재미용 | "참고용 관점" 배지, 조걼문/주의 표현 |

## 2. 도구별 근거 및 라이브러리/데이터 후보

### 2.1 사주(만세력)

| 항목 | 내용 |
| --- | --- |
| 근거 유형 | 고전 명리학 규칙 + 천문 역법(절기, 태양시, 균시차) |
| trustTier | `verified`(계산), `conventional`(해석) |
| 입력 | 양/음력 생년월일시 + 출생지 경도 |
| 출력 | 4주(년월일시 천간지지), 지장간, 십성, 12운성, 12신살, 오행 백분율, 신강/신약, 용신, 대운/세운/월운 |
| 핵심 계산 | ① 음력↔양력 변환 ② 절기 기준 월주 산정(입춘 세수) ③ 자시(23:00\~01:00) 처리: 조자시/야자시 옵션 ④ 진태양시 보정(경도 차이 + 균시차) ⑤ 1948\~1988 한국 서머타임 예외 테이블 ⑥ 십성/오행/신강신약/용신 산출 |
| 라이브러리/데이터 후보 | **음력↔양력 변환(권장 1순위)**: `kor-lunar`(npm) — 한국천문연구원(KASI) 음력·양력 변환 데이터 기반, MIT, 오프라인 동작, 별도 의존성 없음. **대안**: `korean-lunar-calendar`(npm, MIT). **천문/절기**: `astronomia`(npm, MIT) 또는 VSOP87 기반 경량 구현. **Python 대안(참고용)**: `skyfield`(MIT), `ephem`(LGPL). **참고**: 골든 케이스(1980-03-19 01:45 대구 남)로 교차 검증 필수. |
| 라이선스/정확도 비고 | `kor-lunar`는 KASI 데이터 기반 MIT로 상용·비공개 배포 모두 가능. `korean-lunar-calendar`도 MIT. `skyfield`는 MIT, `ephem`은 LGPL. **Swiss Ephemeris는 AGPL/Commercial dual license이며 네트워크 서비스(웹앱/모바일)에 사용 시 AGPL 또는 상업 라이선스 필요** → 기본 후보에서 제외. 명리학적 절기/자시/지역시/서머타임 규칙은 라이브러리에 포함되지 않으므로 자체 구현 + 골든 테스트 필요. |
| \[CONFIRM\] | ① 정확도 검증용 공개 만세력 사이트 N건 선정 ② 천문 계산 엔진 확정(경량 MIT vs 상업 라이선스) |

### 2.2 별자리(Western Astrology — Sun Sign)

| 항목 | 내용 |
| --- | --- |
| 근거 유형 | 서양 점성학 전통 상징 체계(황도 12궁) |
| trustTier | `conventional` |
| 입력 | 양력 생년월일 |
| 출력 | 태양궁, 경계일 처리, 간단한 상징적 키워드 |
| 핵심 계산 | 생일 → 태양황경 → 12궁 분할. 경계일(예: 3월 20\~21일)은 연도별 정확 태양위치로 처리. |
| 라이브러리 후보 | **기본**: 양력 생일 → 12궁 날짜 범위 테이블(자체 구현, MIT). **고급 정확도(경계일)**: `astronomia`(npm, MIT)로 태양황경 계산. **대안(라이선스 주의)**: `swisseph`/Swiss Ephemeris WASM — AGPL/Commercial dual license로 기본 사용 불가. |
| 라이선스/정확도 비고 | 12궁 태양경계는 매년 미세하게 변동(±1일). 일반 사용자에게는 날짜 테이블로 충분하며, 경계일 출생자만 `astronomia` 정확 계산 적용. 별자리 해석은 상징심리적 관점(`conventional`)으로 포지셔닝. |

| \[CONFIRM\] | 사용할 144괘 인덱스 산출 알고리즘의 출처(고전/논문/공개 구현) 확정. |

## 5. 글로벌 도메인 추가 이유 및 활용 방향

- **점성학**: 서양(트로피컬), 인도(사이드리얼), 일본(九星気学), 켈트(나무 상징)는 모두 "생일 → 상징" 구조를 가지지만 해석 프레임이 다릅니다. 사용자는 하나의 문화권에 고정되지 않고 여러 관점을 비교할 수 있습니다.
- **심리학**: MBTI 대신 빅파이브, 애착 이론 등 학술적으로 더 널리 검증된 모델을 함께 제공하면 "단정 라벨"보다 "성향 스펙트럼" 관점을 강화할 수 있습니다.
- **UI/신뢰도 표시**: 모든 모듈은 `trustTier`와 출처(EvidenceRef)를 노출하며, `conventional`/`caution` 도메인은 "문화적 관점" 또는 "자기성찰용"으로 명확히 구분합니다.
