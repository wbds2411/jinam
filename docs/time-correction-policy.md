# 출생 시각 및 진태양시 정책

버전: 1.0 (2026-07-13)

## 기본 입력

- 날짜는 출생지의 민간시(local civil time) 기준 양력 날짜로 받는다.
- 음력 입력은 `kor-lunar`로 양력 변환 후 계산한다.
- 시간대 오프셋은 위치 데이터와 함께 명시한다. 현재 UI는 한국 도시만 지원하며 UTC+9(540분)를 사용한다.
- 해외 출생지, DST, 역사적 시간대 변경은 아직 지원하지 않는다.

## 경도 보정

현재 진태양시 보정은 다음 식의 **경도 보정만** 적용한다.

`보정 시각 = 민간시 + (출생지 경도 - 표준 자오선 경도) × 4분`

표준 자오선은 `UTC 오프셋 시간 × 15°`로 계산한다. 예를 들어 대구 128.6014°에서 01:45 KST는 약 01:19로 보정된다.

## 포함하지 않는 요소

- 균시차(Equation of Time)는 계산하지 않는다.
- DST 및 역사적 시간대 데이터베이스는 적용하지 않는다.
- 위치를 선택하지 않으면 시각을 보정하지 않는다.

‘진태양시’라는 UI 표현은 위 제한을 함께 표시해야 한다. 정밀 천문시를 보장한다는 의미로 사용하지 않는다.

## 날짜 경계

엔진은 두 정책을 제공한다.

- `civil`(기본, 웹 사용): 보정 시각이 전날/다음 날로 넘어가도 일주는 입력한 민간시 날짜를 유지한다.
- `adjusted`: 보정 날짜를 일주에도 적용한다.

연주와 월주는 두 정책 모두 원래 민간시 날짜를 사용한다. 자시의 일주 교대는 전승별 차이가 있으므로 `zishiBoundary`와 날짜 경계 정책을 별도로 기록한다. 계산 결과의 `raw.notes`에는 날짜 이동과 적용 정책을 남긴다.

## 회귀 데이터

`engine/src/tests/fixtures/saju-regression.json`은 버전·정책·출처·검증일을 포함한다. 현재 값은 `kor-lunar 1.6.1`과 프로젝트 절기 정책의 회귀 기준이며 독립 외부 만세력 검증 완료를 의미하지 않는다. 한국천문연구원 등 독립 기준과 대조한 경우에만 `independentExternalVerified`를 `true`로 바꾼다.
