# 프로젝트 진행 현황

> 점검일: 2026년 7월 14일  
> 대상: 결정의 나침반(Compass)  
> 한 줄 결론: **컴퓨터에서 시험할 수 있는 베타 버전은 완성됐지만, 일반 사용자에게 출시하기 전 확인할 일이 남아 있습니다.**

## 1. 지금 어느 단계인가요?

현재 프로젝트는 **로컬 웹 MVP 베타 후보** 단계입니다.

쉽게 말하면 다음과 같습니다.

- 주요 화면과 기능은 만들어졌습니다.
- 자동 테스트와 웹 빌드는 정상적으로 끝납니다.
- 안드로이드 시험용 앱 파일도 만들어졌습니다.
- 하지만 자동 배포 검사 일부가 실패하고 있습니다.
- 실제 안드로이드 기기 시험, 법률 문구 확정, 사주 계산 외부 대조가 필요합니다.

따라서 현재 상태는 **개발자와 제한된 시험 사용자가 점검할 수 있는 단계**이며, 스토어나 공개 서비스에 바로 출시할 단계는 아닙니다.

## 2. 완료된 기능

### 사용자 보호와 개인정보

- PIN으로 앱을 잠글 수 있습니다.
- 생년월일과 상담 기록 같은 민감한 정보는 암호화해 저장합니다.
- 저장에 실패했을 때 평문으로 대신 저장하지 않도록 막았습니다.
- 민감한 질문은 가능한 한 로컬 AI로 보내고, 외부 AI를 쓸 때는 동의와 마스킹 절차를 적용합니다.
- 내보내기 파일에는 API 키가 포함되지 않습니다.
- 사용자가 자신의 데이터를 모두 삭제할 수 있습니다.

### 상담과 계산 기능

- 사주와 여러 전통 해석 모듈이 연결되어 있습니다.
- 심리 검사와 일상 안내 기능이 있습니다.
- Ollama, OpenAI, Anthropic 또는 규칙 기반 답변을 선택할 수 있습니다.
- 자해·타해 위험 신호가 감지되면 운세 해석을 중단하고 도움받을 곳을 안내합니다.

### 실행과 배포

- 웹앱과 PWA가 빌드됩니다.
- Docker를 이용한 개인 서버 배포 구성이 있습니다.
- 같은 네트워크나 Tailscale을 통해 다른 기기에서 접속할 수 있습니다.
- 안드로이드 시험용 APK가 생성되어 있습니다.

## 4. 아직 해결해야 하는 문제

### 출시를 막는 문제

1. **원격 자동 검사 실패**
   - GitHub Actions에서 품질 검사와 Android 작업이 실패했습니다.
   - 같은 품질 검사는 로컬에서 통과하므로 실행 환경 차이를 찾아야 합니다.

2. **Android 실기기 검증 부족**
   - 실제 휴대전화에서 설치, 잠금, 재실행 복구, 암호화 저장, 오프라인 동작을 확인해야 합니다.

3. **사주 계산의 독립 검증 부족**
   - 현재 내부 테스트 자료는 통과합니다.
   - 독립된 외부 만세력과 절기·자시·경도 경계 사례를 비교해야 합니다.

4. **법률·운영 정보 미확정**
   - 운영 주체, 개인정보 담당자, 연락처, 관할법, 분쟁 처리 절차를 확정해야 합니다.

5. **배포 라이선스 파일 없음**
   - README에는 ISC라고 적혀 있지만 저장소 최상위 `LICENSE` 파일은 없습니다.

### 베타 품질을 위해 필요한 개선

- 문서에 적힌 플러그인 구조와 배포 타깃 기능이 실제 코드에는 완전히 구현되지 않았습니다.
- 문서가 목표 구조와 현재 구현을 구분하도록 고치거나, 빠진 기능을 구현해야 합니다.
- 핵심 계산 코드의 테스트 범위를 문서 목표인 90% 이상으로 높여야 합니다.
- 천문 계산 라이브러리 파일이 커서 첫 화면 속도를 실제로 측정하고 최적화해야 합니다.
- 기본 로컬 AI 모델, 기본 클라우드 AI 정책, 토정비결 공식 출처를 확정해야 합니다.

## 6. 출시 판단 기준

다음 조건이 모두 충족되면 공개 베타 출시를 검토할 수 있습니다.

- 원격 자동 검사가 모두 통과한다.
- 실제 Android 기기에서 핵심 흐름이 정상 작동한다.
- 외부 자료로 사주 계산 정확성을 확인한다.
- 개인정보처리방침과 이용약관의 운영 정보를 확정한다.
- 배포 라이선스를 명확히 한다.

현재 기능 개발은 상당 부분 완료됐습니다. 다음 단계의 핵심은 **새 기능을 늘리는 것보다 출시 위험을 하나씩 제거하는 것**입니다.
