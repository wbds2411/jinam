# 기간별 운세·꿈해몽·생활 맥락 AI 해석 적용 기록

2026-10-11 구현. 공통 기준은 `~/w/ops/vibe/commons/AGENTS.md`, `contracts/ai-providers.md`, `contracts/ux-patterns.md`, `CATALOG.md`를 읽고 적용했다. 서버는 공통 Python `vibe_ai` 모듈을 직접 import하며 공급자 어댑터를 복제하지 않는다. 기존 디자인 토큰·입력 컴포넌트·PIN 암호화 저장·저장 실패 재시도를 재사용한다.

## 연결된 기능

기간 선택 → 본인 사주 및 기간 간지 계산 → 선택한 가족 사주 계산·공간 설명·생활 맥락 구성 → 선택한 각 AI 연결에 요청 → 자료 출처 id와 응답 형식 검증 → 모델별 결과 표시 → 필요한 결과만 암호화 기록에 저장.

꿈은 사전 상징·수비학 계산을 참고자료로 제공하고 AI가 자유 서술을 해석한다. 번호는 AI가 제시한 근거 있는 상징 후보를 중복 제거 후 여섯 수로 구성하며 부족한 수만 무작위 보완한다. 후보별 임의 상징 대응과 무작위 보완을 표시한다. 자유 질문은 인생·가족·복권 질문도 받으며 모델의 추가 질문에 이어서 답할 수 있다.

AI 설정은 공통 카탈로그 12종 전체를 표시하며 여러 연결을 등록·활성화한다. 키는 서버 0600 파일에 저장하고 API 응답에서는 제거한다. 외부 전송 동의, localhost 전용 접속 검사, same-origin 세션, 로컬 주소 제한, Docker CLI 차단을 구현했다. 등록한 연결은 개인 서버 차원에서 공유한다. 인터넷 공개·다중 사용자 서비스가 아니다.

JSON 응답 완료 표시, 출처 id, 번호 범위·근거, 일부 미래 확정 표현을 검증하며 실패하면 같은 모델에 한 번 수정 요청한다. 성공한 모델의 결과는 다른 모델 실패 시 유지한다. 공급자 자동 대체를 하지 않는다. 기다림/해석/수정 단계와 무응답 오류, 중지, 해당 연결 재시도를 제공한다. 자연어 해석 전체의 사실성을 기계적으로 보장하지는 않는다.

## 검증

- TypeScript 타입 검사 및 engine/web production build 통과. 큰 JS chunk 경고는 남아 있다.
- Vitest: 기존 63개와 AI 자료·스트림·번호 구성·기간 흐름 테스트 6개 통과.
- 서버 unittest 9개: 세션·Host·Origin 검사, 키 비노출·파일 권한·기존 키 유지, 외부 동의·로컬 주소·CLI 게이트, 형식 수정 요청·자동 대체 없음, 미완료 응답 거부, 비활성/삭제, 번호/출처/확정 표현 검증.
- 재사용한 공통 `vibe_ai` 테스트 12개 통과.
- Playwright 휴대폰 화면: PIN 설정·프로필 입력, 가족/공간 저장, UI에서 연결 두 개 등록, 체크한 자료 구성, 성공 결과 유지와 실패 연결 재시도, 후속 질문, 결과 암호화 저장 후 재접속, 가로 넘침과 페이지 오류 확인. 생성 결과는 이 브라우저 테스트에서 모의 응답을 사용하고 연결 설정 API·저장은 실제 실행한다.
- 실제 Ollama `igorls/gemma-4-E4B-it-heretic-GGUF:latest`에 합성 꿈·가족·공간 자료를 전송해 완료 JSON과 근거별 번호 후보 수신 확인. 기존 단어 사전 응답이 아닌 모델 생성임을 확인했다. 다른 공급자의 실제 계정 로그인·유료 호출은 수행하지 않았다.
- Docker 설정을 추가했지만 현재 환경에 Docker가 없어 이미지 빌드·컨테이너 실행은 검증하지 못했다.

## 범위

가족 사주는 입력이 있을 때 실제 계산한다. 공간은 사용자 설명에 따른 AI 풍수 상징 해석이며 지도·주소·현장 측량이나 정밀 지리 분석이 아니다. 월운은 주별 일주 표본, 연운은 매월 15일의 월주 표본이며 절기 전체·대운 교체 시점을 정밀 종합한 분석이 아니다. 당첨 예측은 제공하지 않는다.
