## 사람·맥락·원하는 가치·현재 저항

필요할 때 고민과 선택 기준을 적고 다음 행동을 정리하려는 개인을 대상으로 한다. 구매자·승인자와의 역할 분리는 현재 해당 없다. 화면 접점은 웹/PWA이며 첫 가치는 자신의 고민 또는 행동 한 문장을 기록하고 다시 열어 보는 것이다. 일일 방문이나 체류 시간을 목표로 삼지 않는다.

코드에서 관찰한 문제는 실제 측정 없이 고정된 컨디션 막대, 출생 사주만으로 만든 오늘의 운 문구, 미연결 상담을 제공하는 듯한 버튼, 이름 없는 입력, PIN 오류 무응답, 적용되지 않는 테마, 새로고침 후 암호화 기록 미복원, 삭제 직후 기존 프로필 재저장이다. 실제 사용자 관찰 결과와 구별한다.

## 선택한 모듈과 구현

1. **신뢰·불확실성 해소**: 실제 데이터가 없는 컨디션·일일 운세와 가짜 상담 응답을 없앴다. 현재 제공하는 기록 기능과 미제공 자동 상담·운세·타로를 구분한다. 기존 대화는 보존하고 이전 안내로 표시한다. 해석 도구의 비중은 정확도가 아닌 선호라는 설명을 붙였다.
2. **통제·복구**: PIN 입력의 라벨·4~6자리 조건·오류·처리 상태, PIN 해제 후 복원, 저장 직렬화·실패 상태·재시도, 암호화 없는 저장 방지, 명시적인 과거 평문 마이그레이션, 전체 내보내기, 저장 대기 후 삭제를 구현했다. 삭제는 취소 가능하며 다른 앱의 저장소를 지우지 않는다.
3. **공통 표현과 입력**: 의미별 CSS 색상 토큰과 Tailwind v3 연결, 16px 본문, 주요 조작 44px 이상, 라이트·다크, OS 초기 테마, 포커스·선택 상태·라벨·오류 연결, 모션 감소, 좁은 화면 재배치를 적용했다. 오행 색상은 장식선과 문자 라벨로 유지했다.
4. **첫 사용과 복귀**: 모든 프로필 입력을 건너뛰고 기록할 수 있다. 예시 문장은 입력란에서 편집하며 즉시 전송하지 않는다. 이전 기록을 시간과 함께 표시한다. 사용하지 않는 출생 지역·건강 정보 신규 수집을 제거했다. 기존 정보는 내보내기에 포함된다.

가격·구독·할인·보상·푸시 알림 모듈은 제외한다. 현재 결제나 해당 운영 정책이 없고 이번 목표에 필요하지 않다. AI 설정은 선호 저장만 하며 실제 외부 전송은 없다. 실제 제공되지 않는 기능에 대한 보증을 추가하지 않는다.

## 규칙의 성격

- **[표준]** 제공 문서의 텍스트 대비·포커스·라벨·리플로우 기준을 검사 대상으로 사용했다. 일부 검사 통과를 WCAG 전체 준수로 선언하지 않는다.
- **[기본값]** 에메랄드 주요 행동, 슬레이트 화면, 4/8px 간격, 16px 카드 반경, 44px 주요 버튼, 150ms 색상 전환. 오방색은 사주 표현에 남긴다. 생리적 효과를 주장하지 않는다.
- **[연구]** 참고 문서의 인식 지원·자율성 원칙을 참고했지만 이 프로젝트의 효과를 입증한 것으로 취급하지 않는다.
- **[가설]** 선택 입력 건너뛰기, 편집 가능한 문장 예시, 실제 저장 상태는 첫 기록 완료와 재사용을 도울 것이다. 아직 사용자 실험 결과는 없다.

## 검증 결과

- TypeScript 검사와 프로덕션 빌드 성공.
- 기존 엔진 45개·프라이버시 6개 테스트, 추가 저장 회귀 6개 테스트 통과.
- 추가 회귀: 연속 수정 저장 순서, 키 없는 평문 저장 방지와 재시도, 저장 공간 부족 복구, 잘못된 키의 복호화 실패, 과거 평문 암호화 전환, 진행 중 저장 후 삭제·타 앱 보존.
- 실제 Chromium: 첫 PIN 설정, 잘못된 PIN 오류, Enter 제출, 프로필 건너뛰기, 기록 저장, 새로고침·PIN 해제 후 복원, 테마 선택, 숫자 입력과 슬라이더 일치, 내보내기 요청, 사주 미리보기, 삭제 취소·완료.
- 320px 라이트·다크와 1280px 화면 확인, 사주 미리보기의 200% 글자 확대에서 수평 넘침 없음. 키보드 포커스 표시와 모션 감소, 오프라인 안내 확인. 브라우저 실행 오류 없음.
- 브라우저 저장 공간 오류를 강제로 발생시켜 실패 문구 → 재시도 → 새로고침 후 기록 복원을 확인했다.
- 고정 토큰의 라이트·다크 본문/배경, 보조문/표면, 주요 버튼, 오류/표면, 경고/배경은 4.5:1 이상, 입력 경계/표면과 포커스/배경은 3:1 이상을 산식으로 확인했다. 모든 조합과 보조기기 검증은 아니다.
- 엔진을 사용하는 온보딩을 지연 로딩해 기본 JS 청크를 약 1,745kB에서 190kB로 분리했다. 온보딩 청크는 약 1,556kB로 빌드 경고가 남는다. PWA 사전 캐시는 해당 청크를 포함하므로 전체 다운로드량 감소나 현장 성능 개선을 입증한 것은 아니다.

## 지표·한계·다음 검증

주요 지표는 과제 관찰 세션에서 첫 기록 작성 후 다시 열기에 성공한 인원 / 해당 과제를 시작한 인원이다. 첫 파일럿은 신규·재방문·키보드 사용자 5~8명을 대상으로 진행할 것을 제안하며, 표본 수를 전환율 입증 근거로 쓰지 않는다. 보호 지표는 저장 실패·복구 실패·의도하지 않은 삭제와 기능 오해다. 데이터 손실이나 실패를 성공으로 표시하는 문제가 발견되면 배포를 보류한다.

이번 변경은 무작위 A/B 실험이 아니며 MDE·관찰 기간·실험 표본은 미설정이다. 고객·민감정보 분석 이벤트를 새로 수집하지 않았다. 실제 사용자 과제 관찰, 스크린리더, 실제 기기의 한글 IME, OS·모바일 조합, 현장 LCP/INP/CLS와 재이용 효과는 미검증이다. 브라우저 파일 다운로드 이후의 보관·가져오기는 지원 범위 밖이다. PIN 복구, 클라우드 동기화, 자동 상담·외부 AI 연동도 미구현이다.

다음 검토 시점은 실제 사용자 파일럿 후와 AI 연결을 활성화하기 전이다. AI 전송·비용·상담 안전 흐름은 구현과 함께 다시 검토한다. 현재 표현·복구 개선은 채택하고, 성과 효과의 확정과 추가 성장 기능은 보류한다.
